# Stylized sci-fi pistol

Modeled in Blender from the concept "Sci Fi Gun Concept" by Amelia Rubin (ArtStation: https://www.artstation.com/artwork/nEKDVX), as a personal modeling study. The concept design belongs to its author.

- `stylized_pistol.blend` / `stylized_pistol.glb` - model
- `build_stylized_pistol.py` - script that builds the model (side-view profiles traced from the concept, extruded in layers)
- `compare_concept_vs_model.png` - concept (top) vs orthographic side render (bottom)
