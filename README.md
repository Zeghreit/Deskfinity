# Deskfinity

Лёгкий органайзер иконок рабочего стола для Windows. Рисуешь на обоях именованный
бокс — и складываешь в него группу ярлыков, которые сами раскладываются по сетке.

Один файл на Python + PyQt6, без установщика и без фоновых служб.

## Установка

1. Положи `deskfinity.py` и `Deskfinity.bat` в одну папку.
2. Запусти `Deskfinity.bat` — он сам поставит PyQt6, если его нет, и стартанёт
   приложение через `pythonw` (без окна консоли).

Вручную:

```
pip install PyQt6
pythonw deskfinity.py
```

## Как пользоваться

| Действие | Как |
|---|---|
| Создать бокс | Клик по иконке в трее, или **Ctrl+Alt+F** → обвести область на десктопе |
| Добавить ярлыки | Перетащить файлы/папки из проводника прямо в бокс |
| Переименовать группу | Двойной клик по заголовку |
| Открыть элемент | Двойной клик по иконке |
| Переставить иконки | Перетащить внутри бокса (появляется маркер вставки) |
| Двигать / менять размер | Тянуть за заголовок / за края (7 px зона) |
| Прокрутка | Колесо мыши, если иконок больше, чем влезает |
| Настройки | ПКМ внутри бокса |

## Что настраивается (ПКМ в боксе)

- **Цвет подложки** — палитра
- **Прозрачность** — слайдер 0–255 прямо в меню, применяется вживую
- **Цвет текста** подписей
- **Размер иконок** — 32 / 40 / 48 / 64 / 80 / 96 px
- **Скругление углов** — 0 / 6 / 10 / 16 / 24
- **Сортировка** по имени или по типу
- **Свернуть в заголовок** (роллап)
- **Зафиксировать** — блокирует перемещение/ресайз, чтобы не сдвинуть случайно
- **Убрать битые ссылки** — чистит записи на удалённые файлы
- **Удалить бокс** — сами файлы не трогаются

## Поведение

- Иконки берутся из системного кэша Windows в размере **jumbo (256×256)** через
  `SHGetImageList` + `IImageList::GetIcon`, поэтому на 96 px они не мылятся.
  Прозрачные поля обрезаются автоматически.
- Иконки внутри бокса раскладываются в сетку с **пропорциональным** распределением
  свободного места: при изменении ширины меняется число колонок, и остаток
  делится поровну между промежутками.
- Боксы всегда остаются **под всеми окнами** — перехват `WM_WINDOWPOSCHANGING`
  с принудительным `HWND_BOTTOM`. В таскбаре не светятся (`Qt.Tool`).
- Файлы **не перемещаются** — хранятся только пути.
- Битые ссылки рисуются полупрозрачными.

## Данные

Конфиг: `%APPDATA%\Deskfinity\boxes.json` — обычный JSON, можно править руками.
В трее есть пункт «Открыть папку настроек».

При первом запуске раскладка автоматически подхватывается из конфигов предыдущих
сборок если они есть, и пересохраняется в новое место.

Автозапуск включается из трея (пишет ключ в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).

## Известные ограничения

- Только Windows (иконки и z-order завязаны на WinAPI).
- Оригинальные иконки рабочего стола не скрываются — если хочешь чистый стол,
  вынеси файлы в отдельную папку и отключи значки через ПКМ по столу → Вид →
  Отображать значки рабочего стола.
- Нет быстрого скрытия всех боксов по двойному клику на пустом месте стола —
  можно добавить.
